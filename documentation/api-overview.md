# OpenINF API reference

This reference covers the public API of all ten OpenINF packages. It is
generated from the same TypeScript source and JSDoc comments that ship in each
release, so a symbol's signature and its documentation always describe the same
version.

## Start with a package

Choose a package from [the package index](packages.md), then use its module page
to find the exported functions, types, classes, and variables it provides.

Most applications begin with `@openinf/util` for general guards, validators, and
assertions. Use `@openinf/util-core` directly when its foundational types and
predicates are all you need.

## Versioning

All ten packages share one release version, so a signature found under one
package describes the same release as every other page here. The version is in
the address of this page, and every release keeps the reference it was published
with: a link into an older version keeps describing that version rather than
following the latest source.
